# Project Requirements

## Hardware
- Windows laptop/PC or any computer capable of running a modern web browser
- Internet connection for Google Colab
- Recommended: 4 GB+ RAM

## Software
- Google Chrome, Microsoft Edge, or Mozilla Firefox
- Google account
- Google Colab
- Python 3 environment (provided by Colab)
- Git/GitHub account for version control and submission

## Python Packages
- TensorFlow / Keras
- NumPy
- Matplotlib
- Seaborn
- OpenCV
- Pillow
- Scikit-learn

## Input Requirements
- Handwritten digit image in PNG/JPG format
- Recommended image content: one clearly visible digit
- The notebook resizes the input to 28×28 pixels before prediction

## Functional Requirements
1. Load MNIST data.
2. Preprocess the image data.
3. Train a neural-network model.
4. Evaluate the model.
5. Upload/read an external digit image.
6. Predict the digit.
7. Display the prediction.

## Non-Functional Requirements
- Simple and reproducible execution in Google Colab
- Clear project documentation
- Maintainable notebook structure
- Easy-to-understand prediction workflow
